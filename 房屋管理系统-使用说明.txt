========================================
          打包APK的正确流程
========================================

1. 进入项目文件夹
   cd E:\新项目\house

2. 运行打包命令（自动完成编译、复制资源、生成APK）
   npm run release

3. 更新版本号（手动改两处）
   - 打开 src/version.ts，改版本号
   - 打开 android/app/build.gradle，改 versionCode 和 versionName

4. 复制APK到桌面
   APK生成位置：E:\新项目\house\android\app\build\outputs\apk\release\app-release.apk
   桌面APK名称：房屋管理-v版本号.apk

========================================
          已知问题及解决方法
========================================

1. APK安装后白屏
   原因：打包时忘了设置基础路径
   解决：确保用 npm run release 打包（已自动设置）

2. APK安装后显示旧版本
   原因：资源文件没有同步
   解决：打包命令已包含资源同步

3. APK文件过大（超过2MB）
   原因：dist文件夹有历史版本的残留文件
   解决：打包前清理旧文件

4. 版本号乱跳
   原因：每次构建都会自动加1
   解决：只在真正需要发布时才打包
